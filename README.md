# LexCrew Doc

Word デスクトップの文書画面で、ローカル LLM を使って法律文書の点検・起案・文面の直しを行う Windows アプリです。作業ウィンドウに指示を書くと、開いている文書を読んで文面を整えます。**チャットに出た文章はそのまま文書には入りません。** 文書を変える操作は、Word の変更履歴に残ります。

開発者: 弁護士　吉田秀平

## できること

### 点検・起案・書き換え

- 自由入力で「この条項を点検してコメントして」「この条を書き換えて」「請求の趣旨を起案して」などと指示できる
- 文字や段落の書式も変えられる。表、罫線、ページ余白は変えられない
- 文書への変更は変更履歴に残る。同じ段落の書き換えは、違った部分だけが履歴に残る。チャットに出た文章は文書には入らない
- 対象は横書きの `.docx` と Word デスクトップ。Word on the web、`.doc`、保護ビュー、読み取り専用、縦書きは対象外

### コメントと変更履歴

- コメントを付けられる。相手のコメントと変更履歴も読める
- コメントへの返信、変更の受入れ・却下はできない

### 参考情報の利用

モデルは必要に応じて次の情報を参照します（設定でオン・オフや URL を指定）。

| 機能 | 説明 |
|------|------|
| **ウェブ検索** | SearXNG で公開ウェブを検索する |
| **Argos** | 同一 PC 上の Argos 索引（社内資料など）を検索する。作業ウィンドウで参照するフォルダを選べる |

### ファイル

- 作業ウィンドウに **クリップかドラッグ＆ドロップで添付したファイル** の内容を読み、文面に活かせる
- 対応形式: PDF、テキスト、Markdown、HTML、JSON、画像（PNG・JPEG・GIF・WebP）、Word（.docx）、Excel（.xlsx）
- 画像やスキャン PDF は、設定した LLM の画像読み取りを使う

### 履歴

- **会話の履歴** … これまでのやり取りを保存し、別のスレッドに切り替えて再開できる
- 文書を開き直すと、その文書でいちばん最近更新した会話が開く

### その他の UI

- 設定のフォント・サイズ・行間は、本文が無い文書を書くときに使う。本文があるときは近くの本文に合わせ、チャットで指定した項目が優先する
- コンテキスト使用量のメーター表示
- 思考モード・ツール呼び出し回数などの詳細設定

## 動作のイメージ

```
Word（Office JS） ── 作業ウィンドウ（Web UI）
                         │
                         ▼
               ローカル常駐（HTTPS :28765）
                         │
        ┌────────────────┼────────────────┐
        ▼                ▼                ▼
  ローカル LLM       SQLite 履歴      SearXNG / Argos
```

- 同梱の **トレイアプリ** が常駐し、作業ウィンドウを Word に登録する
- 文書の読み書きは Word の API 経由。LLM との通信と履歴 DB は常駐側が担当する
- タスクペインから LLM や Argos へは直接叩かない

## 動作環境

- **OS** … Windows 10 / 11（64bit）
- **Word** … Microsoft 365 の Word デスクトップ。横書きの `.docx`
- **WebView2** … 未インストールの場合はインストーラの案内に従って追加
- **LLM** … OpenAI 互換 API（例: ローカルの MTPLX など）。URL と API キーを設定画面で指定
- **任意** … SearXNG、Argos（同一 PC のローカル索引。既定は `http://127.0.0.1:17890`）

管理者権限は不要です。現在のユーザー向けにインストールされます。

## インストール（利用者向け）

1. 配布物の `LexCrew-Doc-Setup-1.2.0.exe` を実行する（バージョンは配布物に合わせる）
2. 管理者の昇格は出ない。インストール先は `%LOCALAPPDATA%\GURI`。スタートメニューのフォルダ名の既定は **LexCrew Doc**
3. 完了画面の「デスクトップショートカットを作成する」と「LexCrew Doc を実行」は既定オン。ログイン時の起動は、セットアップが成功した時点で有効
4. Word で横書きの `.docx` を開き、ホームタブの **LexCrew** で作業ウィンドウを出す
5. 接続で LLM の URL・API キー・モデル名を入れる

会話の履歴（`%APPDATA%\GURI`）は、アプリを入れ直しても残ります。接続設定は LexCrew 系アプリと共有し、`%APPDATA%\LexCrew\connection.json` に保存されます。

旧 Electron 版の GURI が入っているときは、先に外してください。手順は [docs/usage.md](docs/usage.md) にあります。

## 開発者向け

詳しい手順、接続、文書の渡し方は [docs/usage.md](docs/usage.md) にあります。設計上の判断は [docs/design-notes.md](docs/design-notes.md) にあります。

### 必要なもの

- Node.js（パッケージ作成時は 22 系でビルド）
- Rust stable と Windows の MSVC ビルドツール

### コマンド

```bash
npm install
npm run dev-server    # 開発用 HTTPS + webpack（https://127.0.0.1:28765）
npm start             # 開発用サーバ + Word へのサイドロード
npm test              # Vitest と cargo test
npm run package       # release/ にインストーラ一式を生成（要 Windows）
```

### 主なディレクトリ

| パス | 内容 |
|------|------|
| `src/taskpane/` | 作業ウィンドウ UI |
| `src/sidecar/` | 開発用 API・LLM プロキシ・履歴 DB |
| `src/shared/` | プロンプト・ツール定義・共有ロジック |
| `src-tauri/` | トレイ常駐（Rust / Tauri） |
| `scripts/package.ps1` | リリース用の一括ビルド |

## 注意

- 生成された文面は **下書き・点検用** です。法律意見ではありません。判例・条文番号は未確認として扱ってください。
- Word に出典として入るのは、ウェブ検索で当たったページの題名と URL、Argos で当たった資料の題名とファイルの場所だけです。
- 本リポジトリのソースをビルドしただけでは Word に登録されません。`npm run package` で作ったインストーラから導入してください。
